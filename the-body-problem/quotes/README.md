# Quotations for boundary testing

One Markdown file per quotation. This folder is a working collection of potentially useful passages, **not** a set of established findings, and is distinct from the project's literature inventory in `../sources/`.

Use a short descriptive filename, preferably `author-year-short-topic.md`; add a suffix if multiple quotations share a topic. Preserve each quotation's original wording, punctuation and language. Do not invent missing words, page numbers or verification claims. Avoid long copyrighted extracts; keep only the passage necessary for the point.

Suggested note structure (omit unknown information rather than fabricate it):

```markdown
# Author – short topic

## Quotation

> Exact passage, if checked against the source.

## Source

Author. (Year). Full publication details. DOI or stable URL.
Page number / section / paragraph / location: [as available]
Edition or translation: [where relevant]

## Verification

Status: verified against primary source / transcribed but not checked / secondary quotation
Checked by and date: [if verified]

## Context

Brief account of the surrounding argument. Distinguish source-based paraphrase from interpretation.

## Relevance

Boundary test(s): BT-XX
Conception(s) in our provisional map: [if applicable]
SE observation or LLM interpretation: [label explicitly]
Why this passage may matter: [briefly]
```

A secondary quotation must be identified as such until its primary source is checked. A paraphrase is not a quotation. Recording a quotation does not mean its interpretation is agreed. Link relevant notes from boundary-test files when they become useful; there is no need to categorise every quotation in advance.
